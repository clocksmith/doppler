# Paired pointwise operator acceptance

Component: `doppler.runtime-source.gpu.kernels`. Scope: the authorized paired-intermediate implementation. Existing scalar paths and the application runtime pin remain unchanged. This is operator and ownership evidence, not a passing model, signed partition, memory-budget, or application qualification.

Seven registered WGSL variants implement paired add, scalar scale, in-place scale, multiply, gated SiLU, gated sigmoid, and unary SiLU. They consume the numerical owner's generated compensated and elementary helper sources. The existing residual, scale, and SiLU facades route only explicit paired Tensor metadata; malformed or mixed representations reject before allocation. The same unified executor handles immediate and recorded work. Scale/SiLU preserve a complete logical input shape, while explicit prefix requests return their prefix shape. The paired FFN uses separate gate/up tensors; row-split and non-null `swigluLimit` are rejected until their declared paths are supported.

The activation target is the already approved F64 sigmoid/SiLU equation. The new path does not retain the scalar shader's exponent-input approximation clamp at ±15. This is an explicit numerical correction toward the approved equation, not removal of a model-authored clipping policy. The optional model `swigluLimit` is not silently discarded. Inputs include ±16, ±40, ±104, and ±1000, with nonzero low components.

The first physical runs exposed a real binding mismatch: the unary scale shader's unused second input disappeared from the automatically inferred GPU pipeline layout, while the registry still declared that binding. `mac-scale-failure.json` and `amd-scale-failure.json` preserve those failures, including the explicit AMD validation errors. Unary scale and unary SiLU now have their own exact binding layouts. In-place scale uses a single read-write binding rather than overlapping read/write aliases.

`mac.json` and `amd.json` bind the tested shader, facade, wrapper, registry and rule-bundle bytes. Each runs 26 actual public-wrapper controls: immediate/recorded × owned/borrowed output for add, scale, multiply, gated SiLU, gated sigmoid and unary SiLU, plus both in-place scale paths. Outputs are compared with independently evaluated F64 equations at a frozen normalized error limit of 6e-12. Active and deferred pool ownership must both settle; reusable buffers are separately counted, then the pool/device and owned browser close. There are no throughput claims.

`cpu-contracts.log` covers incorrect representation, dimensions, mixed precision, aliases, nonfinite scale, unsupported clipping/row-split options and injected bind failures. Failed recorded outputs stay with the recorder until cleanup; caller-owned inputs/outputs are not released. Types, style, architecture, uniform writers, and registry checks are retained separately. Shared registry, generated helpers/writers and index exports are owned by the numerical agent's coordinated source checkpoint; this scoped commit does not independently qualify that unfinished whole-model execution path.

Final physical result: both GPUs pass all 26 cases; maximum normalized equation error is 1.5543122344752192e-15. At the final repository check, the concurrently introduced FFN paired module was not yet in the strict-source inventory. Its type/style rejection is retained in `types-concurrent-ffn.log` and `style-concurrent-ffn.log`, and its owner was notified; this is not reported as a passing repository gate. The subsequent strict-source run also encountered that concurrently added FFN module's incomplete annotations; `strict-source.log` retains those errors. Earlier pointwise strict compilation passed, but this final repository-wide state is not claimed to pass.
