# Qwen3.6 35B-A3B implementation checkpoint

Source checkpoint: `Qwen/Qwen3.6-35B-A3B`, revision
`995ad96eacd98c81ed38be0c5b274b04031597b0`, Apache 2.0.

The new recipe and runtime path represent 40 hybrid layers, 256 routed experts,
eight selected experts per token, 512-wide routed experts and a 512-wide shared
expert. Packed expert banks retain per-expert offsets. The routed branch uses
SILU; the required shared branch adds
`sigmoid(shared_router(x)) * down(SILU(gate(x)) * up(x))` to routed output.
Existing matmul, activation, repeat-channel and residual kernels execute it.
No new WGSL program or catalog promotion is included.

Focused CPU checks cover source architecture/manifest admission, expert loading,
missing shared tensors, routing profiles, packed-only representation and
independent per-expert Q4K row packing. Type, declaration, source-style/unused,
configuration ownership and rule-bundle checks passed in the isolated source.

The physical test `tests/inference/qwen35-shared-expert-gpu.test.js` passed on
Radeon 8060S, Node WebGPU/Dawn Vulkan. Its two-token shared branch matched an
independent CPU formula with maximum absolute error `2.7470784758065747e-8`
under the unchanged `1e-4` tolerance. A second check used nonzero token/expert
offsets with valid 256-byte binding alignment. An initial unaligned tiny fixture
was rejected by the existing validator; the fixture geometry was corrected,
without changing runtime validation or numerical tolerance.

This is component implementation and scoped physical evidence. Full-model
conversion, actual GPU materialization, numerical/source quality, cancellation,
memory and serving performance remain separate acceptance gates. Q4K conversion
is lossy and does not establish equal weights against another engine's Q4_0.
For the planned active-expert route, explicitly configure
`runtime.inference.moe.routing.activeExpertSelection="topk-readback"`;
the all-expert route is not a throughput substitute.

Component: converter, RDRR validation, loader and text MoE execution.
Intent: preserved. Boundary effects: new explicit Qwen packed-expert format and
shared-expert configuration, with no default model, package or deployment change.
