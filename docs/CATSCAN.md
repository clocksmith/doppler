# CATSCAN: Documentation

Component: `doppler.docs`

Parent: [Doppler Repository](../CATSCAN.md)

## Target

Preserve navigable human contracts without competing with machine-readable status or implementation evidence.

## Authority

- Owns durable goals, architecture explanations, specifications, methodology, runbooks, and navigation.
- Does not own current support status, runtime selection state, or evidence outcomes already governed by registries and reports.

## Scope

- Maintained repository documentation and generated documentation destinations.

## Contracts

- Input: [Doppler goals](goals.md), source contracts, policy registries, and retained evidence.
- Output: [Documentation index](INDEX.md), specifications, guides, and generated human-readable views.

## Invariants

- Normative and explanatory documents remain distinguishable.
- Generated status is not hand-edited as an independent authority.
- Documentation claims link to the governing contract or evidence.

## Acceptance

- Documentation generators and contract checks report current outputs.
- Evidence: [API documentation index](api/index.md).

## Non-goals

- Repeating implementation internals or mutable status in every document.

## Freedom

Any implementation is permitted if it preserves these boundaries and passes the acceptance evidence.
