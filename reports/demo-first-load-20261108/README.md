# Demo first-load layout and grid entry points

The reported empty conversation retained the 280px minimum height on
`.chat-surface`. The content-sized override now applies to empty and loaded
conversations. Initial activity controls previously offered only unavailable
options and repeated instructions. Six directly selectable previews now show
real saved numerical maps before any model load. All eighteen supported views
remain in one player; the dense example still cannot claim expert routing.

Preview images are generated by `node tools/generate-activity-previews.js` from
the pinned public recording. `demo/assets/activity-previews.json` binds the
source hash, token position, scale, representation, dimensions and PNG hashes.
The previews are stationary examples, not live model activity. Clicking a map
loads the 20 MB recording into the existing player. It does not run inference.

Color ranges use the initial nonzero finite 99th-percentile magnitude for each
view/window, fixed across subsequent token positions. These scales are retained
in recording exports and validated on import. Per-view scaling is disclosed;
color intensity is not a comparable magnitude across different views.
