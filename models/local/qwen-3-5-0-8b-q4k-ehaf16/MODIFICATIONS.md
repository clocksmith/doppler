Doppler changed the upstream files as follows:

- **Weights:** converted from safetensors to Doppler shards. Body weights and
  the LM head are quantized to Q4_K, and embeddings are kept in f16
  (`quantizationInfo` in [manifest.json](manifest.json)). The conversion
  config is `src/config/conversion/qwen3/qwen-3-5-0-8b-q4k-ehaf16.json`, digest
  `sha256:0dc4434639c098aa9ff724dd89028996ff43d888ab14b5293d61613fc424766a`.
  The shards are not stored in this repository.
- **manifest.json:** generated by the Doppler converter. It is not an upstream
  file, though it embeds values from the upstream `config.json`.
- **tokenizer.json:** re-serialized. Its parsed JSON equals upstream
  `tokenizer.json` (upstream sha256 `5f9e4d4901a92b99…`, 12,807,982 bytes;
  this copy `8fc3b6de02de5a8e…`, 9,088,480 bytes). Only whitespace and key
  layout differ.
